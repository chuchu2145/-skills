# 活动加分表单制作 Skill

根据活动策划案与收集表，自动生成活动基础分表和附加分表两份 Excel。

## 它解决什么问题

过去需要人工在空白模板里逐行对照收集表和策划案填写学院、学号、姓名、班级、项目题目、分值、分类、日期、排名等信息，容易漏填、错行、覆盖公式。本 skill 把这件事流程化：模板结构不动，只填该填的格子，填不准的地方留黄并回报原因。

## 安装

将activity-bonus-form-builder目录整体放入 skill 加载目录即可，无需额外配置：

```
activity-bonus-form-builder/
├─ openai.yaml   # skill 入口描述（显示名、简述、默认提示词）
└─ SKILL.md      # 执行规范，模型据此工作
```

`openai.yaml` 只负责让宿主识别这个 skill；实际行为完全由 `SKILL.md` 定义。修改行为请改 `SKILL.md`，不要动 `openai.yaml` 里的 `name`。

## 触发方式

默认提示词：

```
使用 $activity-bonus-form-builder 制作本次活动的加分表单。
```

只有**明确要求制作活动加分表单／基础分表／附加分表**时才会触发。让它读一份策划案、整理人员名单、处理普通 Excel，都不会误触发。

## 使用前准备

在工作根目录下准备好 `材料` 和空的 `成果`，按 SKILL.md 中的目录结构放好该活动的空白模板、收集表和策划案。

同时在提示词里**一次性提供**以下 5 个字段，缺任何一项 skill 都会拒绝开工并列出缺失项：

| 字段 | 示例 |
| --- | --- |
| 赛事级别 | 国家级 |
| 学年 | 2025-2026 |
| 获得日期 | 2025/11/03 |
| 个人排名 | 2（仅附加分表） |
| 申请二级分类 | 学科竞赛（仅附加分表） |

可直接复制这段模板填写：

```
赛事级别：
学年：
获得日期：
个人排名：
申请二级分类：
```

这些值不接受从策划案或收集表里猜，必须由你给出。

## 使用流程

1. 放好材料与模板，清空或确认 `成果` 下无同名目录。
2. 发送触发提示词 + 上述 5 个字段。
3. skill 自行解析、匹配、写入，过程中不会回问（字段已在第 2 步收齐）。
4. 结束后读取回报，按提示补齐黄色单元格对应信息后重跑或手动补填。

## 你会得到什么

- `成果/{活动目录}/` 下两份 Excel 的绝对路径。
- 一份问题清单：字段冲突、黄色留空单元格、无法唯一匹配的人员、材料只读校验结果。

黄色（`FFFF00`）只涂在目标单元格上，表示"这里值不确定或明显错误，已主动留空"，不是格式错误。

## 关键机制

**材料只读 + 哈希校验。** 开工前对 `材料` 下所有文件记录哈希，结束前复核。任何材料文件被改动即判定任务失败。所有写入只发生在 `成果` 里，模板是通过复制到 `成果` 后再编辑的。

**模板保真。** 不使用 pandas，也不新建工作簿重写，而是用 `openpyxl` 在复制出的原工作簿上做最小范围修改，从而保留工作表顺序、合并单元格、字体边框、列宽行高、数字格式、公式、冻结窗格、打印设置、数据验证、条件格式和隐藏状态。模板里没有的字段不新增，没有的数据行不擅自加。

**字段有明确来源优先级。** 人员信息（学院/学号/姓名/班级）优先取用户输入，其次收集表，最后策划案；项目题目、分值、平台分类反之，策划案优先。赛事级别、学年、获得日期、附加分表的个人排名与专项赛标记只认用户输入。高优先级来源给出明显错误值时不会偷偷降级采用低优先级值，而是留黄上报。

**匹配靠学号。** 优先按学号对齐记录，学号不可用时才用"姓名 + 班级"组合。匹配不唯一时不做猜测归属。

**标题固定写法。** 两份表顶部合并单元格分别写入：

- `雅安-机电学院-【机】{活动名称}基础分表（26.25.24.23基础分）`
- `雅安-机电学院-【机】{活动名称}附加分表（26.25.24.23附加分）`

模板若缺少对应合并区域，skill 会停止并报告，不会自行重建模板。

## 环境依赖

- Python 3
- `openpyxl`（读写 xlsx，核心依赖）
- 可解析 PDF / DOCX 策划案的库

不需要 Office 或 Excel 本体。

## 常见问题

**Q：只提供了部分字段会怎样？**
A：不会开始制作，也不会生成任何最终文件，直接列出缺失项让你补充。不要指望它用黄色留空绕过。

**Q：能同时处理多个活动吗？**
A：不能。一次只处理一个活动目录；目录不唯一时会先请你确认。

**Q：想改填报规则怎么办？**
A：改 `SKILL.md` 的字段取值规则、冲突处理或制作流程部分，`openai.yaml` 通常不用动。改动后注意同步"完成前验证"一节，避免规范自相矛盾。

**Q：为什么我的材料文件时间戳变了？**
A：不应该变。哈希校验若通过则内容未变；若报失败，请检查是否有其他程序同时打开了材料文件。

## 已知限制

- 仅处理 xlsx；旧版 xls 需先转换。
- 依赖模板结构稳定，模板大改（表头、合并区域、数据行变化）后需先验证再批量使用。
- 不负责事后修正：黄色单元格的补齐需要你提供信息后重新运行或手工填写。
