# 活动加分表单制作

## 适用范围

仅在用户明确要求制作活动加分表单、基础分表或附加分表时使用。不要因为用户只是处理一般 Excel、整理人员信息或阅读活动策划案而触发本 skill。

## 输入与输出

工作根目录下必须存在 `材料` 和 `成果`。将某个活动的完整目录名记为 `{活动目录}`，它由工作日期和活动名组成。始终原样使用材料中已有的 `{活动目录}`，不要重新拼接、规范分隔符或改名。

```text
材料/
└─ {活动目录}/
   ├─ 空白基础分表.xlsx
   ├─ 空白附加分表.xlsx
   └─ {活动目录}材料/
      ├─ *.xlsx
      └─ *策划案.pdf # 也可能是.docx文件

成果/
└─ {活动目录}/                 # 由本 skill 创建
   ├─ 【机】{活动名称}基础分表.xlsx
   └─ 【机】{活动名称}附加分表.xlsx
```

- `{活动名称}` 是解析后的项目题目／活动名称。文件名中的 `【机】` 是固定文字，不属于占位符。
- `材料` 目录及其全部内容必须保持只读。不得原地编辑、覆盖、移动、改名、删除或另存材料文件；所有写入只能发生在 `成果` 中。
- 开始前记录材料文件的哈希；结束时复核。任何材料文件哈希发生变化都表示任务失败。
- 若目标目录或目标文件已经存在，不得静默清空或覆盖，先检查现有内容并避免破坏用户文件。

## 开工前置检查

先定位唯一的目标活动目录，并确认两个空白模板、一个或多个收集表以及策划案均可识别。若用户提示或目录内容不足以唯一定位活动，先让用户确认，不要猜测。

检测工作区环境是否可用Python 3、openpyxl、powershell 7等工具及其替代方案，如缺少工具以致可能影响正常使用应向用户询问，切勿擅自开工。

以下字段只能来自用户输入，必须一次性确认齐全：

- `赛事级别`
- `学年`
- `获得日期`
- `个人排名`（仅附加分表）
- `申请二级分类`（仅附加分表）

任何一项缺失时，拒绝开始制作，列出缺失项并等待用户补充。不得用收集表或策划案中的值代替这些用户输入；不得用黄色留空绕过缺失的必填用户输入。基础分表的 `个人排名` 不受此限制，固定填写数值 `0`。

## 字段取值规则

先按模板中的真实表头识别字段，不要假定固定列号。模板中不存在的字段不要新增；模板中不存在的数据行不要擅自新增。

| 目标字段 | 取值优先级 |
| --- | --- |
| 学院、学号、姓名、班级 | 用户输入 > 收集表 > 策划案 |
| 项目题目（活动名称）、分值、平台一级分类、平台二级分类 | 策划案 > 用户输入 > 收集表 |
| 赛事级别、学年、获得日期、附加分表的个人排名、附加分表的是否为专项赛 | 仅用户输入 |
| 基础分表的个人排名 | 所有数据行均填写数值 `0` |

按数据对象对齐记录时，优先使用学号匹配；学号不可用时再使用姓名与班级组合匹配。无法唯一匹配时，不要猜测归属，在目标单元格填黄色并留空，同时记录问题。

## 冲突、错误与缺失

- 同一字段存在多个来源值时，按上表选择最高优先级的有效值，并完整记录冲突位置、各来源值以及最终采用值。
- 高优先级来源未提供某字段时，按顺序取下一个存在的来源；来源未提供但其他来源有有效值时，不视为错误。
- 若最高优先级候选值明显错误，不要静默改用低优先级值。将目标单元格填黄色底色并留空，再向用户报告。
- 若所有可用来源都没有某字段的有效值，将目标单元格填黄色底色并留空，再向用户报告。
- 黄色填充使用 Excel 标准纯黄色 `FFFF00`。只标记无法确定或明显错误的目标单元格，不涂整行。
- 不得编造、推测或从其他人员记录补齐缺失值。

## 制作流程

1. 完成开工前置检查，并记录 `材料` 中所有文件的哈希。
2. 解析空白模板、全部收集表和策划案。以空白模板的合并区域、表头、数据行和公式为准，使用模板表头而不是固定位置映射字段。
3. 按学号，或姓名与班级组合，把各来源记录对应到目标数据行；先解决冲突与缺失，再开始写入。
4. 在 `成果` 下新建 `{活动目录}`，将两个空白模板复制到该目录并保留原文件名作为工作副本。不得直接使用或修改材料中的原文件。
5. 使用 `openpyxl` 打开工作副本，如没有`openpyxl`应向用户报告。只写入已确定的字段值、固定值 `0`、黄色留空标记和顶部标题；优先保留模板原有公式和格式，项目题目为`【机】{活动名称}`。
6. 在两个工作簿最上方的合并单元格左上角分别写入完整的 `雅安-机电学院-【机】{活动名称}基础分表（26.25.24.23基础分）` 和 `雅安-机电学院-【机】{活动名称}附加分表（26.25.24.23附加分）`。若模板没有对应合并区域，停止并报告模板结构异常，不要自行重建模板。
7. 保存并重新打开工作副本验证。确认无误后，将基础分表工作副本改名为 `【机】{活动名称}基础分表.xlsx`，将附加分表工作副本改名为 `【机】{活动名称}附加分表.xlsx`。
8. 重新计算材料目录文件哈希，并执行下方完成前验证。

## Excel 处理要求

- 必须保留工作簿的工作表名称与顺序、合并单元格、字体、边框、对齐、列宽、行高、数字格式、公式、冻结窗格、打印设置、数据验证、条件格式及隐藏状态。
- 不要用 pandas 或新建工作簿的方式重写模板；应在复制的原工作簿上做最小范围修改。
- 日期按yyyy/mm/dd格式写入；若模板将日期作为日期型单元格处理，应写入日期值而不是任意文本。
- 不得覆盖数据区域之外的公式或说明文字，除非该位置明确是待填写的目标单元格。

## 完成前验证

- `成果/{活动目录}` 中最终保留两份且仅两份规定命名的 `.xlsx` 表单，没有残留的空白模板工作副本。
- 两个工作簿均可正常打开，目标工作表和全部原有工作表仍然存在。
- 两个顶部合并单元格的标题完全正确。
- 所有可确定字段均已按优先级写入；所有黄色单元格均为空，且已记录原因。
- 基础分表每一数据行的 `个人排名` 均为数值 `0`；附加分表的个人排名全部来自用户输入。
- 所有冲突、明显错误、无法唯一匹配及黄色留空位置均已记录。
- `材料` 中所有文件哈希与开工前一致。

## 向用户汇报

完成后报告两个输出文件的绝对路径，并集中列出：

- 每个冲突的字段、位置、各来源值和最终采用值。
- 每个黄色留空单元格的位置、字段、原因及需要用户确认或补充的内容。
- 无法唯一匹配的人员记录。
- 材料只读校验结果。

若因缺少用户专属必填项而停止，明确列出缺失字段，并说明尚未开始制作或尚未生成最终文件。
